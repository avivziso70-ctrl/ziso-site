# פורטל ספקים למחירונים (11.11.2026)

ספק מקבל קישור אישי `https://www.zisoceramics.com/supplier/?t=<token>` ומעלה כל קובץ (אקסל, CSV, PDF, תמונה).
הפונקציה `supplier-upload` שומרת את הקובץ בדלי הפרטי `supplier-files`, וקוראת אותו לטבלה `sp_prices` (סטטוס pending):
- אקסל/CSV: המודל רואה רק 40 שורות ראשונות בכל גיליון ומחזיר מיפוי עמודות; כל השורות ממופות בקוד (זול גם לקובץ ענק).
- PDF/תמונה: המודל קורא את המסמך ומחזיר שורות.

הצוות נכנס ל-`/crm/prices.html` (אותה כניסה של ה-CRM):
- **חיפוש מחיר**: רק מחירים מאושרים, מהזול ליקר, עם מחשבון רווח (עלות × (1+רווח) × 1.18 אם לפני מע"מ). מחיר בן יותר מחצי שנה מסומן "ישן".
- **לאישור**: תצוגה של 15 שורות, אישור (rpc `sp_decide`) או דחייה, פתיחת הקובץ, קריאה מחדש.
- **ספקים וקישורים**: הוספת ספק (מרשימת ספקי פריוריטי), העתקת קישור, קישור חדש, השבתה, העלאה בשם ספק.

## פרטיות
- לכל ספק: שם עסק, מספר ספק בפריוריטי, טלפון איש קשר עסקי (לא חובה). שם השולח בטופס לא חובה.
- הקבצים בדלי פרטי, רק לצוות (RLS `crm_me()`), קישור צפייה זמני ל-5 דקות.
- אין שליחה אוטומטית לספקים. שליחת קישור לספק רק באישור של אביב.
- מגבלות: 20MB לקובץ, 30 העלאות ביום לספק, סוגי קבצים מוגבלים.

## קבצים
- `schema.sql`: טבלאות, פונקציות, דלי (מריצים פעם אחת ב-SQL Editor של Supabase).
- `supplier-upload/index.ts`: הפונקציה (פרוסה, verify_jwt=false, בודקת token בעצמה).
- `docs/supplier/index.html`, `docs/crm/prices.html`.
